# 快捷键

## Trae IDE

| 功能           |      快捷键      |
| -------------- | :--------------: |
| 打开文件       |     Ctrl + O     |
| 保存文件       |     Ctrl + S     |
| 复制       |     Ctrl + C     |
| 粘贴       |     Ctrl + V     |
| 打开快捷键设置 | Ctrl + Shift + S |
| 关闭当前文件   |     Ctrl + W     |
| 切换文件       |    Ctrl + Tab    |
| 切换/搜索文件  |    Ctrl + P/E    |
| 关闭当前标签   |     Ctrl + W     |
| 向下行选择     |     Ctrl + L     |
| 删除行         | Ctrl + Shift + K |
